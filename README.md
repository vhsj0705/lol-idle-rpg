# 협곡 키우기 — LoL 챔피언 방치형 RPG

리그 오브 레전드 챔피언 173명으로 만든 방치형 RPG입니다. 구조는 쿠키런: 크럼블(데브시스터즈, 2026.07 출시)을 참고했습니다.

## 실행
`serve.ps1`로 로컬 서버를 띄운 뒤 http://localhost:8123 에 접속합니다.
```
powershell -ExecutionPolicy Bypass -File serve.ps1
```
챔피언 이미지와 원작 스킬 설명은 Riot Data Dragon CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 확률 데이터 (넥슨 오픈API)
장비 강화와 큐브 확률은 넥슨 오픈API의 메이플스토리 기록으로 만듭니다. 강화에는 스타포스 기록, 큐브에는 등급 상승 기록을 씁니다. API 키는 저장소에 넣지 않고, 아래 스크립트로 한 번 받아서 확률 숫자만 `probability.js`에 저장합니다.
```
$env:NEXON_API_KEY = '발급받은 키'
powershell -ExecutionPolicy Bypass -File tools\nexon-probability.ps1 -Days 90
```
- 기록 API는 키를 발급한 계정의 사용 기록만 돌려줍니다. 그래서 표본이 적은 단계는 기본 확률과 섞습니다(표본 50건이면 반반).
- 확률이 다른 기록(슈페리얼 장비, 찬스 타임, 파괴 방지)은 제외합니다.
- `probability.js`가 비어 있으면(`null`) 게임은 기본 확률을 씁니다. 대장간 화면에 지금 어떤 확률을 쓰고 있는지 표시됩니다.

## 쿠키런: 크럼블 → 협곡 키우기 대응
| 쿠키런: 크럼블 | 협곡 키우기 |
|---|---|
| 쿠키 자동 전투 + 스킬 | 챔피언 자동 전투, 게이지가 가득 차면 고정 스킬 자동 발동 |
| 편성 시너지 | 포지션 시너지(5포지션 모두 편성 시 +20%) + 역할군 시너지(2/3/4명) |
| 쿠키 뽑기 | 협곡 소환 (중복 카드 → ★ 성급 강화) |
| 오븐 + 행운 반죽 장비 뽑기 | 대장간 + 마법공학 부품 장비 제작 (자동 제작/장착/판매) |
| 메인 스테이지 | 챕터 10개(데마시아~공허) × 10스테이지, 이후 심연 난이도로 반복 |
| 임플란트 타워 | 공허의 탑 (층별 보스, 보석 보상) |
| 방치 보상 | 접속하지 않은 시간 최대 8시간분의 골드/부품/보석 |

## 성장 기획
- **수치 단위**: 숫자가 지나치게 커지지 않도록 레벨·스테이지에 따른 성장률과 ★·등급 배율을 제곱근 수준으로 낮췄습니다. 진행 속도(스테이지별 필요 레벨)는 이전과 비슷하게 맞췄습니다. 이전 저장 데이터의 골드는 같은 가치로 자동 변환됩니다.
- **레벨**: 골드를 쓰며, 비용은 `20 × 1.068^(Lv-1) × 등급 배율`입니다. 등급 배율은 일반 ×1, 희귀 ×2, 영웅 ×3.5, 전설 ×5입니다.
- **레벨 한계**: `★ × 20 + 10`이라서 ★1은 30, ★6은 130까지 올릴 수 있습니다. 한계에 닿으면 소환으로 중복 카드를 모아 성급을 올려야 합니다.
- **성급(★)**: 중복 카드 1/2/4/8/15장과 골드 `200 × 1.79^(★-1) × 등급 배율`이 필요합니다.
- **등급별 능력치**: 등급마다 기본 배율이 6배씩 차이 납니다(일반 ×1, 희귀 ×6, 영웅 ×36, 전설 ×216). 레벨당 +0.56%, ★당 +7%라서 한 등급 안에서 Lv1 ★1부터 Lv130 ★6까지 최대 약 2.9배 오릅니다.
  - 그래서 아무리 강화해도 다음 등급의 Lv1 ★1 챔피언을 넘지 못합니다. 포지션 차이로 가장 약한 챔피언과 비교해도 15% 이상 낮습니다.
  - 같은 강화 단계끼리는 등급마다 전투력이 약 5.4~5.9배 차이 납니다.
- **등급별 스킬 개수**: 일반 1개, 희귀 2개, 영웅 3개, 전설 4개(Q/W/E/R 전부)입니다. 첫 스킬은 기존 고정 스킬이고, 추가 스킬은 남은 키 중에서 정해지며 효과는 역할군에 맞게 정해집니다. 스킬 이름은 원작(Data Dragon)을 따르고, 전투에서는 가진 스킬 중 하나를 무작위로 골라 씁니다. 마나 바는 다음에 쓸 스킬의 비용 기준으로 찹니다.
- **스킬과 마나**: 스킬 위력은 궁극기(R)가 ×1.9이고, 챔피언마다 ×0.75~1.3의 차이가 있습니다. 마나 총량은 모든 챔피언이 100입니다. 스킬 마나 비용은 위력에 비례합니다(위력 1.0 = 마나 40, Q/W/E는 30~52, R은 57~99). 마나 바의 노란 선이 다음에 쓸 스킬의 비용 위치입니다. 마나 회복 속도는 챔피언마다 달라서 평타 1회당 5.6~10.4가 차고, 초당 자연 회복은 그 1/8입니다.
- **챔피언 대결**: 각 챕터의 5번째 스테이지(1-5, 2-5 …) 마지막 웨이브에 그 챕터 지역의 챔피언 3~5명이 나옵니다. 적 챔피언도 스킬을 쓰므로 일반 스테이지보다 권장 전투력이 높습니다.
- **편성**: 최대 10명입니다. 포지션·역할군 시너지 외에 지역(13종, 2/4/6명), 특수 조합(2~10명), 단독(1명) 시너지가 있습니다. 목록은 `data.js`의 `SYNERGIES`에 있습니다.
- **권장 전투력**: 적의 총 체력과 초당 피해로 위협도를 계산합니다. 전투 시뮬레이션에서 승률 약 83%가 되는 전투력에 맞춰 보정했습니다 (`5.09 × 위협도^0.81`, 탑은 ×1.57, 챔피언 대결은 적 챔피언 3/4/5명일 때 ×1.4/1.7/2.0).
- **장비**: 무기·방어구·투구·장갑·신발·장신구 6칸입니다. 등급마다 LoL 완성 아이템이 정해져 있고, 이미지도 그 아이템의 것입니다. 능력치 개수는 일반 1개부터 신화 5개까지입니다.
- **장비 등급**: 기본 수치가 등급마다 2배씩 차이 납니다(일반 2.19%, 희귀 4.38%, 영웅 8.75%, 전설 17.5%, 신화 35%, 주 능력치·iLv 0 기준). 장비 레벨당 +1.25%입니다. 같은 iLv라면 +25까지 강화해도 다음 등급 +0을 넘지 못합니다.
- **장비 강화**: 골드로 강화합니다(최대 +25, 단계당 능력치 +2.5%). 결과는 대성공 +2~5, 성공 +1, 실패, 하락 -1, 파괴 중 하나입니다. 비용은 `1.32^강화 단계 × (등급+1) × max(600 × (1 + iLv×0.1), 처치 골드(iLv) × 50)`입니다. 후반 골드 수입에 맞춰 함께 오릅니다.
- **보상**: 스테이지의 부품·보석 보상은 초기 버전의 2.5배이며 스테이지가 오를수록 늘어납니다. 공허의 탑 보상은 보석·골드·부품·소환권·챔피언 카드·장비입니다.
- **자동 진행**: 소환권은 한 번에 모두 쓸 수 있습니다. 자동 소환을 켜면 1.5초마다 100회씩(소환권 먼저, 다음은 보석) 소환하고, 보석이 부족하면 멈춥니다. 도감의 모두 강화는 ★ 강화와 레벨업을 한 뒤 자동 편성까지 진행합니다. 공허의 탑은 자동 도전을 켜면 층을 돌파할 때마다 다음 층에 도전하고, 실패하면 멈춥니다.
- **소환 확률**: 일반 55%, 희귀 30%, 영웅 12%, 전설 3%입니다. 10회 소환하면 영웅 이상이 1회 보장되고, 70회 안에 전설이 확정됩니다.
- **포지션 기본 성향**
  - 탑: 체력·방어가 높고 적의 공격을 가장 많이 받습니다.
  - 정글: 치명타 15%를 가집니다.
  - 미드: 스킬 피해 ×1.3이고, 피해 스킬이 광역으로 나갑니다.
  - 원딜: 공격력과 공격 속도가 가장 높습니다.
  - 서포터: 마나 회복이 ×1.2 빠릅니다.
- **스킬**
  - Q/W/E는 마나 비용이 적어 자주 발동합니다.
  - R(궁극기)은 마나 비용이 커서 느리지만, 위력이 ×1.9이고 대부분 광역입니다.
  - 효과 종류는 피해, 군중 제어(기절), 회복, 보호막, 강화 5가지입니다.
